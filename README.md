# Java + VS Code Knowledge Center  
A clean, modern, interactive documentation site for learning **Java** and mastering **VS Code**.  
Built with pure **HTML, CSS, and JavaScript** — no frameworks, no dependencies, no setup required.

## What This Project Is  
This is a full‑screen, modal‑based knowledge center designed to help students, beginners, and self‑taught developers learn Java in a structured, visual, and easy‑to‑navigate way.

It combines the best parts of:

- A reference book  
- A cheat sheet  
- A tutorial  
- A documentation portal  

All inside a fast, animated, single‑page interface.

## Features  
### Clean, modern UI  
- Smooth animations  
- Full‑screen modals  
- Color‑coded callouts  
- Professional documentation layout  

### Organized by topic  
- **Basics** — variables, types, control flow  
- **Syntax** — methods, classes, collections  
- **OOP** — encapsulation, inheritance, polymorphism  
- **Debugging** — breakpoints, stepping, exceptions  
- **Tools** — VS Code, Maven, testing  
- **Advanced** — files, threads, streams  
- **Cheat Sheets** — quick syntax + shortcuts  
- **Interview Questions** — core + OOP questions  

### Built for learning  
- Table of contents in every modal  
- Code examples with syntax highlighting  
- Tips, notes, warnings, and error callouts  
- Back‑to‑top navigation  
- Dense but readable content  

### Zero dependencies  
- No React  
- No frameworks  
- No build tools  
- No external libraries  

Just open `index.html` and it works.

## Why This Exists  
Most Java resources are:

- Too long  
- Too scattered  
- Too confusing  
- Too boring  
- Too outdated  

This project solves that by giving learners a **single, clean, structured place** to study Java — fast.

## How to Use  
1. Download or clone the repository  
2. Open `index.html` in any browser  
3. Click a topic  
4. Read the modal  
5. Copy/paste examples into your Java project  
6. Learn at your own pace
   Or use this link! https://kenn3thg.github.io/Java-VS-Code-Knowledge-Center/

No installation. No setup. No configuration.
